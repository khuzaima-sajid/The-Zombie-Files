
# The Zombie Files 🧟

An interactive educational website exploring the strange and fascinating world of zombies.

## Features
- Zombie history and popular culture
- Zombie science and zombie ants
- Different types of zombies
- Zombie apocalypse survival guide
- Interactive survival supplies checklist
- Supply cost calculator
- Zombie personality quiz
- Contact form
- Light and dark mode toggle

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
The-Zombie-Files/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
